## `[01] $ whoami`

Construyo software pensando primero en cómo se comportan los datos y cómo se comunican los servicios entre sí. Backend, bases de datos y APIs son la base; la nube y la seguridad son las áreas donde sigo sumando profundidad.

No busco atajos. Prefiero entender por qué algo funciona antes de solo hacer que funcione — cada proyecto es una oportunidad para romper algo y aprender a arreglarlo mejor.
